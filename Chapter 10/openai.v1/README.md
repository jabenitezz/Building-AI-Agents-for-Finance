# Chapter 10 — OpenAI-only version

This directory is an OpenAI-only migration of the Chapter 10 lab. The original
`Chapter 10/agentic_rag_lab.py` is left unchanged.

The RAG architecture and the numbered steps are preserved:

- naive RAG
- router query engine
- sub-question decomposition
- self-correcting agentic retrieval
- hybrid dense + BM25 retrieval
- LLM reranking
- hybrid + reranking
- RAG answer evaluation

## Model mapping

The original implementation uses Claude Sonnet 4.6 for generation/reasoning and
OpenAI `text-embedding-3-small` for embeddings.

This version uses only OpenAI:

- **Generation / reasoning:** `gpt-5.6-terra`, reasoning effort `medium`
- **Embeddings:** `text-embedding-3-small`

The Sonnet role is mapped to GPT-5.6 Terra, matching the tier mapping used in
Chapter 8 `openai.v1`. The embedding model stays on the cheaper
`text-embedding-3-small` tier because embeddings do not need the expensive
reasoning model.

All model choices can be changed from `.env` without editing the Python code.
For example, for a premium reasoning run:

```text
OPENAI_LLM_MODEL=gpt-5.6-sol
OPENAI_REASONING_EFFORT=high
```

## Data

This variant reuses the original corpus in:

Chapter 10/data/

## Setup

Run the following commands from `Chapter 10/openai.v1`.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Edit `.env` and set your OpenAI API key:

```text
OPENAI_API_KEY=sk-...
```

Only one provider/API key is required.

## Run the full lab

```bash
python agentic_rag_lab.py
```

This runs steps 3 through 10 in the same order and with the same functional
behaviour as the original chapter implementation.

## Run individual steps

Steps 4, 5, 6, 8, and 10 use the shared per-document indices:

```bash
python -c "from agentic_rag_lab import load_indices, step_4_router; step_4_router(load_indices())"
python -c "from agentic_rag_lab import load_indices, step_5_subquestion; step_5_subquestion(load_indices())"
python -c "from agentic_rag_lab import load_indices, step_6_agent; step_6_agent(load_indices())"
python -c "from agentic_rag_lab import load_indices, step_8_rerank; step_8_rerank(load_indices())"
python -c "from agentic_rag_lab import load_indices, step_10_evaluate; step_10_evaluate(load_indices())"
```

Steps 3, 7, and 9 build their own index/retriever:

```bash
python -c "from agentic_rag_lab import step_3_naive_rag; step_3_naive_rag()"
python -c "from agentic_rag_lab import step_7_hybrid; step_7_hybrid()"
python -c "from agentic_rag_lab import step_9_hybrid_rerank; step_9_hybrid_rerank()"
```

## Notes on compatibility

The OpenAI LLM integration is pinned to a recent LlamaIndex line that knows the
GPT-5.6 model identifiers and supports `reasoning_effort`. The lab still uses
LlamaIndex for routing, decomposition, agents, retrieval, reranking, and
evaluation; only the provider-specific Anthropic layer has been replaced.
